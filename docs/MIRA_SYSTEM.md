# Mira System · 标准化规格

> Mira 的视觉系统单一真相。代码是实现真相源:`src/renderer/shared/theme.css`
> (tokens) + `src/renderer/shared/capsule.css`(组件)。本文件锁定"为什么/是什么"。
> 用户签字:核心 = **The Pulse(呼吸光核)**,容器 = **哑光绿胶囊**。
> 本规格**取代 CHARTER §8.5 的两眼脸**;§8.4 外圆角改为全圆 pill;§8.3 色相仍锁 157。

## 0. 两层
- **功能层(本规格)**:UI 里天天见的 Mira——哑光绿胶囊 + 呼吸光核。克制、原生、全尺寸可用。
- **魂/英雄层(待开发)**:能量玻璃罐 render 的调性,用于 app 图标 / 开场 / 落地页 hero。同源(绿胶囊里的能量),更丰富。

## 1. 容器 · 哑光绿胶囊(`.capsule`)
承载电池/气色的"器皿"。**平涂,不发光**(辉光是之前的过度设计,已废)。
- 形:**全圆 pill**,`border-radius: 999px`(取自落地页 `.island`)。
- 色:`--cap-color`,默认 `rgba(26,107,82,0.97)`(= `#1A6B52` @ .97 = §8.3 满电色);面板/提醒处由 `energyToColor(energy)` 注入**实时气色**(平涂)。
- 阴影:`0 14px 32px -12px rgba(20,20,19,.24)` + `inset 0 0 0 1px rgba(255,255,255,.14)`。
- 胶囊内文字 `#f6f7f9`;进度线 `#6FE7C3` on `rgba(255,255,255,.18)`,高 3px。

## 2. 角色 · The Pulse(`.mira` + `.mira__pulse`)
一枚深色透镜(迷你胶囊)里,一个**会呼吸的光核**。B&O 冷光指示灯那种细腻。
- 透镜:`--lens` 深墨绿径向渐变;尺寸由 `--mf`(透镜高)一处缩放,宽 = `1.55×`。
- 光核:居中的柔光(`#f4fff9 → #8fe6c0 → 薄荷辉 → 透明`)。
- **亮度 = 气色**:`--energy`(0–1)驱动光核不透明度(累了就变暗成余烬)。
- **恒定的是"形与光的语言",不是一张固定脸**;气色由容器色 + 光核亮度共同表达。

## 3. 状态(class 切换,§3 状态表)
| 状态 | class | 光核表现 | 触发 |
|---|---|---|---|
| 安静 · 呼吸 | (默认) | 缓缓涨缩(breathe 5s) | 日常 |
| 感知 · 醒亮 | `.is-bright` | 光溢成场(更大) | 小睡醒来 / 强调 |
| 短歇 · 眨眼 | `.is-blink` | 收成一条竖直微缝 | 一级短歇(§6.1) |
| 小睡 · 深睡 | `.is-rest` | 暗成缓慢的一条横线 | 小睡仪式(§6.3) |
| 精力低 | `--energy↓` | 光变暗、变冷 | 气色下降(§8.3) |

## 4. 尺寸(`--mf`,一套铺满全场景)
| 场景 | `--mf` | 备注 |
|---|---|---|
| 开场 hero / 小睡 | 64 / 92 | 光核居中在绿胶囊里,呼吸 |
| 20 秒提醒入口 | 30 | 胶囊左 + 文字 + 进度线 |
| 菜单栏面板主体 | 34 | 光核亮度随实时精力 |
| 菜单栏 tray | (单色 · 待做) | 蒸馏成"胶囊剪影 + 亮点/微缝" |
| app 图标 | (待做) | 光核在玻璃罐里的魂版 |

## 5. 动效
- 呼吸:`scale(1↔1.14)`,`ease-in-out` 5s。深睡:不透明度慢脉动 6s。眨眼:瞬时收缝(无动画,靠 350ms transition)。
- `prefers-reduced-motion` 时全部停呼吸。

## 6. 待开发(签字方向,尚未落地)
