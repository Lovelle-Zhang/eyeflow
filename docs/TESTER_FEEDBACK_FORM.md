# EyeFlow 试用反馈

把这几个问题发给测试者就够了。

这是私测反馈表。请测试者不用写长报告，按真实感受回答即可。

## 请先确认测过这些

- 第一次打开 EyeFlow。
- 看第一次打开能不能理解 Mira 是谁。
- 点开始后等几分钟，感受第一次轻提醒。
- 看 Mira 是否出现、可拖动、可展开/收起。
- 开始一次专注并点一次 `休息`。
- 在设置里试一次 `强制爱` 预览。
- 看设置里的 `桌面就绪` 是否清楚。
- 点 `复制诊断反馈`，确认能复制反馈文字。

## 5 个核心问题

1. 安装有没有卡住？
2. 第一次打开能不能理解 Mira 是谁？
3. Mira 是舒服、可爱，还是提醒太多？
4. 第一次轻提醒有没有让你感觉 Mira 在陪你？
5. 你还会不会想继续用？为什么？

## 如果愿意多说一点

- 你用的是哪台 Mac / 什么 macOS？
- 你有没有给辅助功能权限？
- Mira 变粉色时，你知道下一步该点哪里吗？
- 哪句话、哪个按钮、哪个界面让你困惑？
- 你最希望 EyeFlow 下一版改什么？

## 如果遇到 bug

请发：

- 一句话描述问题。
- 截图或录屏。
- EyeFlow 设置里的 `复制诊断反馈` 内容。

不用写长报告，随手说真实感受就好。

## 这版不用评价的事

- 不用把 EyeFlow 当医疗诊断工具测试，它不会诊断疾病。
- 不用找云同步，这版默认本地保存。
- 不用测试 Gatekeeper 绕过流程，这版已经 Developer ID signed and notarized；如果 macOS 仍拦截，请直接截图反馈。
