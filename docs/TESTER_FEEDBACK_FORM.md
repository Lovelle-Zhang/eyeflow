# EyeFlow 试用反馈

把这几个问题发给测试者就够了。

## 5 个核心问题

1. 安装有没有卡住？
2. 第一次打开能不能看懂？
3. Mira 是舒服、可爱，还是打扰？
4. 休息提示清不清楚？
5. 你还会不会想继续用？为什么？

## 如果愿意多说一点

- 你用的是哪台 Mac / 什么 macOS？
- 你有没有给辅助功能权限？
- Mira 变粉色时，你知道下一步该点哪里吗？
- 哪句话、哪个按钮、哪个界面让你困惑？
- 你最希望 EyeFlow 下一版改什么？

## 如果遇到 bug

请发：

- 一句话描述问题。
- 截图或录屏。
- EyeFlow 设置里的 `复制诊断反馈` 内容。

不用写长报告，随手说真实感受就好。
