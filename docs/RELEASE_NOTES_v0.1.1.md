# EyeFlow v0.1.1

EyeFlow v0.1.1 is a private/public beta refresh for trusted macOS testers. It keeps Mira's quiet desktop companion experience and focuses on making the Today view and recent recovery overview easier to understand.

## Highlights

- Restored the committed Today page structure with the rhythm card, 5-column daily metrics, quick state note, and daily summary.
- Added a lightweight Today entry that jumps to the recent recovery trend.
- Added week/month overview data on the recent-days page for screen-active time, eye-rest time, recovery count, and note count.
- Kept automatic appearance switching honest as timezone-based when precise location is not available.
- Updated packaged-app smoke coverage for the current rest-screen copy and capture timing.

## Tester Focus

- Install from the DMG and confirm first open is understandable.
- Start a session and check the Today rhythm card, pause/rest actions, and daily summary.
- Open the recent-days page and switch between week/month overview.
- Try one rest flow and confirm the guidance is clear.
- Copy diagnostics from Settings when reporting issues.

## Privacy

EyeFlow is local-first. Private builds do not include a cloud account, analytics backend, or crash reporting backend. EyeFlow does not use camera, microphone, or gaze tracking.

## Medical Note

EyeFlow is a wellness tool, not medical software. If you have persistent eye pain, vision changes, severe dryness, headaches, or other concerning symptoms, take a break and consider consulting a qualified health professional.
