# EyeFlow 网页设计宪法

面向 `landing/` 官网。所有网页视觉改动以本文件为准；与之冲突的一律以本文件为高。
（文案语气仍以 [MIRA_LANGUAGE.md](MIRA_LANGUAGE.md) 为准，本文件只管视觉系统。）

---

## 一、字体系统 — 全站只允许 4 个字号、2 个字重，多一个都算违规

| 角色 | 字号 | 字重 | 用途 |
|---|---|---|---|
| Display | 40–48px（手机 28–32px） | 300 细体 | 每屏最多一句，slogan 级 |
| Title | 20–22px | 500 | 小节标题 |
| Body | 16–17px | 400 | 正文，行高 ≥ 1.8，段间距 ≥ 1.5em |
| Caption | 13px | 400 | 信任行、注释、Footer |

规则：
- 大标题必须细字重（大而细 = 从容，大而粗 = 叫卖）
- 禁止用 bold 强调正文；需要强调用墨绿色或单独成行
- 全站只用一个字体族（`-apple-system, "PingFang SC"` 系统栈），不引入第二字体

## 二、颜色 — 全站 = 暖纸底 + 墨字 + 一点墨绿，没有第四种

- 背景：app 的 `--wash` 暖纸系，全站统一；弃用深色 hero
- 文字：`--ink` 暖墨色；次要文字用 0.55 不透明度，不引入新灰色值
- 墨绿 `--mira`：每屏最多出现一次（CTA 或一个关键词），是点睛不是铺陈
- 禁止渐变、彩色图标、任何第四种颜色
- （例外：Mira 本体是全站唯一的「插画」，保留她自己的配色；真实 app 截图是内容不是装饰）

## 三、留白 — 高级感的第一来源

- 屏与屏垂直间距 160–200px（觉得「太空了」就是对了）
- 内容列宽最大 640px 居中，不通栏铺满
- 一屏只说一件事：一句话 + 一个视觉 + 最多一个按钮
- Mira 周围留大片空白

## 四、装饰 — 做减法

- 边框接近零：分隔靠留白；必须有线时用 `--ink` 6% 透明度发丝线
- 阴影接近零：截图可用极淡一层（y=2, blur=24, 4%），按钮无阴影
- 圆角全站统一一个值（10–12px）
- 禁止：emoji 当装饰、图标堆砌、卡片套卡片、背景纹理

## 五、动效 — 全站只有两种动

1. Mira 的呼吸（全页唯一持续动画，复用 app 那套缓动呼吸 + 眨眼）
2. 滚动入场轻淡入（opacity 0→1 + 上移 12px，600ms ease-out，每屏一次）

禁止：视差、弹跳、hover 放大。Mira 之外一切都是静的。

## 六、结构节奏 — 每屏同一模板：一句 Display → 短正文（≤3 行）→ 一个视觉

页面顺序：

1. Hero（slogan + 呼吸的 Mira + 下载 CTA）
2. → 大留白 → 眼睛三拍（纯文字理性层，用定稿的提炼版）
3. → 大留白 → 认识 Mira（她话很少）
4. → 大留白 → 真实 app 截图 ×2–3（每张配一句宪法语气说明）
5. → 大留白 → 产品哲学四条（一行一条极简：不打断 / 不监控 / 不制造压力 / 本地优先）
6. → 大留白 → 品牌句「EyeFlow —— 守护你看清世界的方式。」+ 下载 + 邮箱

## 七、元规则

每加一个元素前问：删掉它页面会垮吗？不会就删。
