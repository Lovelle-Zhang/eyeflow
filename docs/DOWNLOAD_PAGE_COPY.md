# EyeFlow 下载页文案

这份文案适合放在一个简单试用页上。真正发出前，把下载链接换成实际链接。

## 首屏

EyeFlow

一个面向长期屏幕工作者的 macOS 低打扰恢复系统。

Mira 会陪你记录眼睛状态，在不粗暴打断专注的前提下，带你完成眨眼、远眺和短休息。

按钮：下载 EyeFlow 测试版

链接：隐私说明

## 三句话说明

- 本地优先：眼睛状态和节奏数据保存在你的 Mac 上。
- 不读内容：不读取文档、键盘输入、密码、消息、摄像头或麦克风。
- 非医疗诊断：EyeFlow 只做低打扰恢复建议，不替代医生建议。

## 你可以试什么

- 每天第一次打开，让 Mira 记录一下当下眼睛状态。
- 开始一轮专注，看看休息节奏是否合适。
- Mira 变粉色时点一下，看看休息指引是否清楚。
- 在设置里复制反馈，把真实感受发给我们。

## 测试版提示

这是早期测试版，还没完成 Apple 签名和公证。第一次打开时，macOS 可能会提示需要在 `系统设置 > 隐私与安全性` 里允许打开。

如果你不熟悉这个流程，可以先等正式签名版。

更友好的发送方式：把 `docs/TESTER_SHARE_MESSAGE.md` 里的短消息直接发给测试者。

## 反馈

试完后，告诉我们这 5 件事就够了：

1. 安装有没有卡住？
2. 第一次打开能不能看懂？
3. Mira 是舒服、可爱，还是打扰？
4. 休息提示清不清楚？
5. 你还会不会想继续用？

如果遇到 bug，请在 EyeFlow 设置里点 `复制诊断反馈`，粘贴给我们。
