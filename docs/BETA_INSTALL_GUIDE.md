# EyeFlow 私测版安装说明

谢谢你帮忙试 EyeFlow。这是给可信测试者使用的公开内测版。当前构建已经使用 Apple Developer ID 签名，并已完成 Apple 公证。

请不要公开转发这个安装包。它可以给测试者正常安装，但反馈渠道和发布节奏还按内测管理。

## 下载安装

1. 下载 `EyeFlow-0.1.0-x64.dmg`。
2. 打开 DMG。
3. 把 `EyeFlow.app` 拖到 `Applications / 应用程序`。
4. 在应用程序里打开 EyeFlow。

正常情况下，macOS 会把 EyeFlow 识别为已公证的开发者应用。如果 macOS 仍提示不能打开，请先告诉我们提示原文，不要继续转发这个安装包。

需要校验文件时，可对照发布页里的 SHA256。

## 第一次打开

Mira 会先问你现在眼睛感觉怎么样。按真实感觉打分就好，不用想太多。

如果 EyeFlow 请求 `辅助功能` 权限：这是为了识别当前 App 和空闲时间，方便找更自然的休息点。EyeFlow 不读取文档内容、键盘输入、摄像头或麦克风。

## 帮我试这些流程

1. 第一次打开：看是否能理解 EyeFlow 和 Mira 在做什么。
2. 每日眼睛状态评估：按真实感觉完成打分。
3. Mira 可见性：确认 Mira 出现、可拖动、可展开/收起，需要时能找回。
4. 普通休息：开始一次专注，然后点一次 `休息`，看看恢复指引是否清楚。
5. 强制爱预览：到设置里点 `预览 15 秒`，确认全屏恢复预览能结束并回到 EyeFlow。
6. 设置里的 `桌面就绪`：看看辅助功能权限、开机启动、版本和通知状态是否好理解。
7. 反馈与诊断：在设置里点 `复制诊断反馈`，确认能复制一段本地诊断文字。

## 反馈方式

最简单：直接告诉我这 5 个问题。

1. 安装有没有卡住？
2. 第一次打开能不能看懂？
3. Mira 是舒服、可爱，还是提醒太多？
4. 休息提示清不清楚？
5. 你还会不会想继续用？

如果遇到 bug：打开 EyeFlow 设置，点 `复制诊断反馈`，粘贴给我，再加一张截图最好。

## 不要期待什么

- 这不是医疗诊断，也不会判断疾病。
- 这个版本没有云同步，状态和节奏数据默认保存在本机。
- 这是已签名、已公证的内测安装器；如果 macOS 仍拦截，请把提示截图发给我们。

## 小提醒

EyeFlow 是轻提醒恢复工具，不是医疗诊断。如果你有持续疼痛、视力变化、严重干涩或头痛，请先休息并考虑咨询专业医生。
