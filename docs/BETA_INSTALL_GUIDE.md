# EyeFlow 测试版安装说明

谢谢你帮忙试 EyeFlow。这是早期测试版，还没完成 Apple 签名，所以第一次打开时 macOS 可能会拦一下。

## 下载安装

1. 下载 `EyeFlow-0.1.0-x64.dmg`。
2. 打开 DMG。
3. 把 `EyeFlow.app` 拖到 `Applications / 应用程序`。
4. 在应用程序里打开 EyeFlow。

如果 macOS 提示不能打开：

1. 打开 `系统设置`。
2. 进入 `隐私与安全性`。
3. 找到 EyeFlow 被拦截的提示。
4. 点 `仍要打开`。

还不行的话：在 `Applications` 里按住 Control 点 EyeFlow，选择 `打开`。

## 第一次打开

Mira 会先问你现在眼睛感觉怎么样。按真实感觉打分就好，不用想太多。

如果 EyeFlow 请求 `辅助功能` 权限：这是为了识别当前 App 和空闲时间，方便找更自然的休息点。EyeFlow 不读取文档内容、键盘输入、摄像头或麦克风。

## 帮我试 3 件事

1. 完成第一次眼睛状态打分。
2. 开始一次专注，然后点一次 `休息`。
3. 如果 Mira 变粉色，点一下 Mira，看 EyeFlow 是否清楚地告诉你怎么休息。

有空的话，再试试拖动 Mira、展开/收起 Mira 气泡。

## 反馈方式

最简单：直接告诉我这 5 个问题。

1. 安装有没有卡住？
2. 第一次打开能不能看懂？
3. Mira 是舒服、可爱，还是打扰？
4. 休息提示清不清楚？
5. 你还会不会想继续用？

如果遇到 bug：打开 EyeFlow 设置，点 `复制诊断反馈`，粘贴给我，再加一张截图最好。

## 小提醒

EyeFlow 是低打扰恢复工具，不是医疗诊断。如果你有持续疼痛、视力变化、严重干涩或头痛，请先休息并考虑咨询专业医生。
