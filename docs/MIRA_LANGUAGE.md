# Mira Language — 语言宪法

> 依据 `POSITIONING.md` 的语言原则展开。今后**任何用户可见的文案**(App 内、网页、分享卡、营销)都必须符合本文。写完一句话,先问:这像 Mira 本人说的吗?

## 一、语气内核

像 Mira 本人在说话——生活化、温和、克制、笃定不讨好。她外表不抢风头,内心干净、从容、自己看重自己:该说的说完就安静,不解释、不推销、不表演关心。她不把用眼说成病(不健康化),不把陪伴说成系统(不技术化),不把休息说成绩效(不效率化)。她和你是同一边的——看到什么说什么,如实但从不评判;帮你记得停一下,但停不停始终是你的事。

## 二、五条语气原则

### 1. 说人话,不说系统话

机器汇报状态,Mira 跟你说话。

| ❌ 不说 | ✅ 说 |
|---|---|
| Eye fatigue detected / 监测到疲劳 | 你的眼睛可能有点累了 |
| Break completed / 休息已完成 | 欢迎回来 |
| Session started / 计时开始 | 我在旁边了。你继续专注,休息点到了我再轻轻提醒。 |

### 2. 体感语言,不用方法论词

用户说"我好累/没状态/脑子转不动",不说"我需要 Recovery"。方法论词(Recovery、状态感知、恢复效率)只许出现在代码和内部文档里。

| ❌ 不说 | ✅ 说 |
|---|---|
| Start recovery session / 开始恢复流程 | 一起缓一缓 |
| 提升恢复效率 | 松一口气,下一轮会更轻 |
| 优化你的用眼状态 | 让眼睛歇一下 |

### 3. 陈述与邀请,不命令不评判

Mira 只做两件事:如实说看到的,轻轻发出邀请。决定权永远在用户手里。

| ❌ 不说 | ✅ 说 |
|---|---|
| 你应该休息了 | 我们先停一下? |
| 请立即休息 | 该歇会儿了,我在。 |
| 你休息得不够 | 今天专注已经开始累积,但休息记录还少。 |

### 4. 不制造焦虑,不羞辱

禁分数羞辱、红色警告语气,禁"又/才/只"这类贬义副词(「你**又**跳过了休息」「**才**休息了 2 次」)。数据如实呈现,永不用来指责。

| ❌ 不说 | ✅ 说 |
|---|---|
| 警告:用眼过度! | 有一阵子了,要不要看看远处? |
| 你又忽略了 3 次提醒 | 你最近连续把恢复放到稍后。Mira 会少一点催促,多等自然断点帮你停一下。 |
| 今日达标率仅 40% | 今天休息了 2 次。到断点时停一下,让节奏松一点。 |

### 5. 笃定,不讨好

不卑微求关注、不过度热情、不撒娇、不加语气词卖萌。该说的说完就安静;用户不理,Mira 退回去等下一个自然时机,不纠缠。

| ❌ 不说 | ✅ 说 |
|---|---|
| 求求你休息一下嘛~ | 那先忙,回头我再看节奏。 |
| 太棒了!!你真是最棒的!! | 好了 · 眼睛松过了。 |
| 别忘了我哦,我一直在等你 | 新的一天,我在旁边等你开始动。 |

## 三、禁用词表

出现即打回。同义变体一并禁止。

**系统腔**:detected / 监测到 / 检测到 · completed / 已完成 · session / 会话 · initialized / 已启动 · status / 状态码 · error / 错误 · warning / 警告 · 已同步 · 执行

**效率腔**:效率 / 恢复效率 · 达标 / 达成率 / 完成度 · score / 分数 / 评分 · 打卡 / 坚持打卡 · 生产力 · 绩效 · KPI · streak / 连续记录(作为施压手段时)· 排名 / 超过 xx% 的用户

**健康腔**:疲劳指数 · 用眼过度 · 眼部健康风险 · 症状 · 诊断 · 治疗 / 疗程 · 干眼症(等病名,除非法务要求)· 损伤 / 不可逆(App 内语境;POSITIONING 层面的事实陈述除外)

**评判/施压**:失败 · 不合格 · 你又 / 才 / 只(贬义用法)· 请立即 / 必须 / 应该(命令式)· 最后警告

> 边界说明:「恢复断点」「恢复」在 App 的设置/说明文案里已是既定名词,可继续用;禁的是把 Recovery 当卖点词对用户说、把休息说成流程。
>
> 边界说明二(2026-07-09 拍板):**开发者/技术面板语境的工程术语豁免**——本地诊断、反馈导出、评分模型/置信度等出现在诊断反馈面板与导出文本中的词,属技术支持语言,不受本宪法约束。宪法管的是**用户体验语言**:提醒、引导、观察、分享卡、日常界面。判断标准:这句话是 Mira 在跟用户说话,还是工程师在给工程师留信息。

## 四、常用场景标准句式

每个场景给可用变体;写新文案先从这里挑,挑不到再造——新造的句子必须过第二节五条原则。

### 疲劳提醒(盯屏太久时)

> 方向:轻声、给台阶、偶尔指向真实世界,不吓人。

- 「你的眼睛可能有点累了。」
- 「有一阵子了,要不要看看远处?」
- 「屏幕里的事很多,眼睛也需要被记得。」

### 休息邀请 / 休息开始

> 方向:邀请而非指令,「我在」的陪伴感;引导视线离开屏幕、去看真实的东西——克制地点,不必每句喊看世界。

- 「该歇会儿了,我在。跟我看看远方,20 秒就好。」
- 「一起缓一缓。看向窗外,或屋里最远的那面墙。」
- 「不用盯着屏幕,看远处 20 秒再回来。」

### 休息结束(欢迎回来)

- 「欢迎回来。」
- 「好了 · 眼睛松过了。」
- 「休息完成 · 已记录 ✓」(岛等极小空间的紧凑变体)

### 记录 / 数据呈现(如实、不评判)

> 方向:看到什么说什么;数据是观察,不是成绩单;不够就诚实留白。

- 「今天专注 6 小时 58 分 · 护眼恢复 14 分钟。」
- 「还看不出规律。先陪你慢慢跑几轮,Mira 再把你这几天的节奏一点点看清楚。」
- 「今天专注已经开始累积,但休息记录还少。Mira 会留意恢复断点,别一路撑到底。」

### 鼓励时刻(接住了休息)

> 方向:确认价值,不吹彩虹屁;一句就够。

- 「这一下,眼睛真的松了。」
- 「停二十秒,不是退后,是给下一步蓄力。」
- 「今天的节奏,稳。」

### 低谷时刻(没怎么休息)

> 方向:不指责,「咱们」同盟语气;把责任揽到节奏上,不放到人身上;顺手给一个轻的出口。

- 「今天咱们都撑得有点久。下一个断点,一起停一下?」
- 「你最近连续把恢复放到稍后。Mira 会少一点催促,多等自然断点帮你停一下。」
- 「今天不必一直撑着,Mira 会帮你记得停一下。」

### 分享卡金句

> 方向:平静、有余味,落点在「轻/回来/世界」;不喊口号。App 金句池已是标准,新增的先对味。

- 「给眼睛一点空白,下一轮会更轻。」
- 「看远一点,是把自己从屏幕里接回来。」
- 「看向远处时,身体也在悄悄换气。」

## 五、双层结构在语言里的分工

| 层 | 话术 | 使用频率与场合 |
|---|---|---|
| **功能层**(日常高频) | 累 / 没状态 / 缓一缓 / 歇一下 / 松一口气 / 停一下 | 提醒、岛、气泡、按钮、设置——所有日常触点 |
| **品牌魂**(仪式时刻) | 看清世界 / 看真实的远方 / 把自己从屏幕里接回来 | **只在关键仪式**:全屏休息、分享卡、每日收尾、landing 收尾 |

点睛的东西滥用就不灵了:日常提醒说"歇一下",全屏休息才说"看看真实的世界"。一天里用户碰到"看世界"的次数,应该少到每次都还有分量。

## 六、自检清单

发布任何用户可见文案前过一遍:

1. 这像 Mira 本人说的,还是像系统/客服/健康软件说的?
2. 有没有禁用词(第三节)?
3. 是邀请还是命令?有没有评判?
4. 读完是想歇一下,还是感到焦虑/被烦?
5. "看世界"级别的话,用在配得上它的时刻了吗?
