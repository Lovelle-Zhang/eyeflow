# Mira 语言宪法

> 任何用户可见的文案（app 内、顶部胶囊、面板、开场、营销）都必须符合本文件。
> 内核继承自老项目 992 条话术审计的结晶；场景为新项目（精力电池/胶囊/开场）重写。

---

## 一、语气内核

像 Mira 本人在说话——生活化、温和、克制、**笃定不讨好**。
外表不抢风头，内心干净、从容、自己看重自己。
不健康化、不技术化、不效率化。

一句话尺子：她不求你喜欢她，她只是安静地在、该说的说完、然后退回自己的节奏。

---

## 二、五条语气原则（各配正反例）

1. **说人话，不说系统话**
   - ✗ "Eye fatigue detected" / "会话已开始" / "检测到疲劳"
   - ✓ "你的眼睛可能有点累了" / "欢迎回来"

2. **体感语言，不用方法论词**
   - ✗ "Recovery 完成" / "恢复效率 80%"
   - ✓ "缓一缓" / "松一口气" / "歇过了，清楚一点了"

3. **陈述与邀请，不命令不评判**
   - ✗ "你应该休息" / "你又分心了"
   - ✓ "看看远处吧" / "要不要停一下？"

4. **不制造焦虑不羞辱**
   - 禁分数羞辱、红色警告语气、"又/才/只"这类贬义副词。
   - ✗ "你今天才歇了 1 次" / "专注度下降"
   - ✓ "今天歇了一次，再来一次也好"

5. **笃定不讨好**
   - 不卑微求关注、不过度热情、不撒娇；该说的说完就安静，不多一句。
   - ✗ "别关掉我呀～我会一直陪着你的！"
   - ✓ "那先忙，回头我再看节奏。"

---

## 三、禁用词表

系统腔 / 效率腔 / 健康腔一律不用：
detected、score、warning、失败、坚持打卡、效率、达标、监测到、完成度、
症状、诊断、介入、触发、会话、超时、分心、专注度……

**豁免**：开发者 / 技术面板 / 代码内部标识符（如引擎变量名）——宪法管的是
用户体验语言，不管工程术语。

## 四、场景标准句式（新项目场景，每条给方向 + 2-3 变体，具体待原型定调）

> 以下为方向与草稿，最终字句在视觉原型阶段对着画面定。

**开场 · 自我介绍**
方向：极简第一人称，点明我是谁 + 不打扰 + 提醒歇眼，引出"先试一次"。不软、不讨好。
- "你好，我是 Mira。"
- "我住在你的屏幕角落，不打扰你。"
- "你看屏幕太久时，我会提醒你——歇一下，看看远处。"
- "现在，我们先一起试一次。"

**开场 · 第一个 loop 收尾**（睁眼后，让用户当场感受效果）
- "这样就好。"
- "是不是清楚了一点？"

**开场 · 引导两种休息**
- "刚才那个，是短歇——像眨一次长眼，随时来一下。"
- "累得深了，还可以小睡一会儿——闭眼久一点，歇得更透。"
- "小睡多久，你自己定。"
- "好了，我记住了。之后我就在上面陪着你。"

**提醒 · 顶部胶囊浮出（短歇引导）**
方向：轻、邀请、不催。
- "眼睛歇歇？看看远处。"
- "抬头看看窗外吧。"
- "让眼睛松一下。"

**提醒 · 二级明确（精力很低，建议小睡）**
方向：更明确但仍不指责，"咱们"同盟语气。
- "撑挺久了，这次真的歇一下吧。"
- "要不要小睡一会儿？我陪你。"

**休息完成**
- "欢迎回来。"
- "清楚一点了吧。"

**数据 / 面板呈现**（如实，不评判，不夸大）
方向：陈述事实，把判断权还给用户；不确定就诚实留白。
- "今天用眼 4 小时，歇了 3 次。"
- "还看不出规律。"（诚实留白也是招牌）

**低谷时刻**（今天几乎没歇——不指责）
- "今天一直没停下来。明天，咱们慢一点。"

**品牌魂话术**（用在配得上的仪式时刻，不滥用）
- "守护你看清世界的方式。"

---

## 五、双层结构在语言里的分工

- **功能层话术**（累 / 没状态 / 缓一缓 / 歇歇）——日常高频用。
- **品牌魂话术**（看清世界）——只在关键仪式时刻点睛（开场收尾、完整休息、每日收场），
  点到即止，不滥用。

---

## 六、五问自检（每次落笔前过一遍）

1. 这句是"人话"还是"系统话"？
2. 有没有用到禁用词、或效率腔/健康腔？
3. 是陈述/邀请，还是命令/评判？
4. 会不会让用户感到被羞辱或焦虑？
5. "看世界"级别的话，用在配得上它的仪式时刻了吗？（还是滥用了）
